# 小布在家 · AI 客服分流 Demo

宠物上门服务 AI 客服分流的可交互原型：左侧为用户端（iPhone），右侧为客服工作台，实时展示 AI 的意图判断、风险分级和处理链路。

## 在线访问
开启 GitHub Pages 后访问：`https://<你的用户名>.github.io/<仓库名>/`

## 本地运行
无需安装任何依赖，下载 `index.html` 后用浏览器（Chrome / Safari）直接打开即可。

## 演示场景
| 场景 | 演示重点 |
| --- | --- |
| 售前咨询 | 知识库检索 + 医疗边界，不给用药建议 |
| 订单查询 | 时间与专员来自订单系统，不由 LLM 生成 |
| 改约 | 查询时段 → 规则校验 → 用户确认后才执行 |
| 宠物走失 | P0 强制升级，人工接管，生成工单摘要 |

勾选「模拟订单接口故障」可演示取数失败时 AI 不猜测、直接转人工。

> 说明：当前为前端交互原型，AI 判断为预置模拟，数据均为虚构。
